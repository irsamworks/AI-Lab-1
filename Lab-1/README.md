# Lab 1: Artificial Intelligence Fundamentals

## Project Overview

This project explores the historical development of Artificial
Intelligence, rule-based decision-making, and the limitations of
conversational testing as evidence of intelligence.

## Files

- `lab1_rules.py`: Implements a rule-based scholarship eligibility system
  and executes four core test cases.
- `lab1_compare.py`: Compares conversational responses with rule-based
  decisions using a scholarship example.
- `Lab1_Report.docx`: Contains the historical timeline, implementation
  details, testing results, comparison, limitations, and references.
- `outputs/`: Contains captured program outputs.

## Requirements

- Python 3.10 or later
- Visual Studio Code or another Python-compatible editor

No third-party Python packages are required.

## How to Run

Open a terminal in the project directory.

Run the rule-based system:

```bash
python lab1_rules.py
